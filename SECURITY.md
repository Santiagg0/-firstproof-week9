# FirstProof — Security and Responsible AI

## Data protection
FirstProof uses simulated inventory data.

The prototype does not request names, addresses,
phone numbers or employment documents.

## OpenAI integration
The OpenAI API key is stored in Vercel
environment variables.

The API key must never be included in
public GitHub files or browser code.

## Input validation
The API accepts three integer values
between -999 and 999.

Users must declare whether they used AI assistance.

## Deterministic evaluation
Inventory differences are evaluated using
mathematical rules.

AI generates explanations but does not
change the evaluation score.

## Limitations
FirstProof does not certify real work experience,
identity or professional qualifications.

## Future safeguards
Before a production launch, implement rate
limiting, abuse monitoring and API cost controls.
