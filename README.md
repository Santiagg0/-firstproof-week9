# FirstProof — Week 9

A working, anonymous prototype of the **First-proof** vacuum, not a CV builder or job board.

## Run
`npm start` and open `http://localhost:3000`.

## Test
`npm test`.

## AI integration
Set `OPENAI_API_KEY` **only** in server environment / Vercel settings. If missing or unreachable, feedback is explicitly labeled **simulated**. Deterministic inventory checking still works.

## Status
Local working prototype with automated tests. A public URL, actual two deployments, screenshot-based synthetic persona walkthrough and actual video are not yet verified. Never present placeholder URLs or an invented transcript as evidence.
